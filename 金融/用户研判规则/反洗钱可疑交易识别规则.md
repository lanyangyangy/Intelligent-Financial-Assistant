### AML-RW-001：七日高频识别规则

- 触发条件：客户在观察窗口内出现七日高频行为，单笔或累计金额达到 60,000 元，或交易频次超过 4 次。
- 观察窗口：2 个自然日，跨渠道合并统计。
- 风险等级：medium。
- 处置动作：记录 risk_alert；中高风险生成 work_order；必要时要求客户补充资金来源说明。
- Agent 联动：风控 Agent 发布 risk_alert 事件，投顾 Agent 在推荐前读取 CROSS_AGENT_RISK_ALERT 标签。
